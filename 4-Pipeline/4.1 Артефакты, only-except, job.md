4.1 Артефакты, only-except, job

```
build_app:
  stage: build
  script:
    - mkdir build
    - TIMESTAMP=$(date +%s)
    - echo "$TIMESTAMP" > "build/app-version-$TIMESTAMP.txt"
  artifacts:
    name: "$CI_JOB_NAME"
    expire_in: 1 week
    paths:
      - build/
    
```

artifacts:
Позволяет определять какие артефакты будут писаться в файл

Эта переменная по умолчанию, гитлаб сервер -
$CI_JOB_NAME
Если не задать имя артефакту, то он будет называться по умолчанию (artifacts)

expire_in - срок жизни артефактов

paths - определяет пути к файлам, который будет включаться в ваш артефакт

![alt text](/image_folder/image-28.png)
Хранение последних артефактов. Если последние артефакты не нужны, то это можно отключить для экономии места

Артефакты сохраняются только в случае успешного выполнения задания

## Needs

needs добавляет зависимость
```
stages:
  - test
  - build

test_app:
  stage: test
  script: echo "run util-tests"
  
build_app:
  stage: build
  script: echo "building app"
  
build_image:
  stage: build
  needs:
    - build_app
  script: echo "building the image"
  
push_image:
  stage: build
  needs: ["build_image"]
  script:
    - echo "preparing"
    - echo "pushing image to registry"
  ```

### before_script/after_script

```bash
stages:
  - build
  - test
 
build_app:
  stage: build
  before_script:
    - echo "Execute this command before any 'script:'"
  script: echo "Building"
  after_script:
    - echo "Execute this command after the 'script' "

test_app: 
  stage: test
  script:
    - echo "Run test"
    - echo "test done"
```

Если его сделать до объявления stage, то он станет глобальным
и применит это к каждой Джобе

```
before_script:
  - echo "Этот скрипт выполнится перед КАЖДЫМ job"
  - export SOME_VAR="значение"

stages:
  - test
  - deploy

test-job:
  stage: test
  script:
    - echo "Выполняется тест"
    - echo "Переменная: $SOME_VAR"

deploy-job:
  stage: deploy
  script:
    - echo "Выполняется деплой"
    - echo "Переменная: $SOME_VAR"
```
